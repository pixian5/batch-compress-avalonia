## 四、关键工程事实（供后续开发参考）

- 本机可用的引擎：`/opt/homebrew/bin/7zz`（7-Zip 26.03 arm64）、`/opt/homebrew/bin/rar`（RAR 7.23 Trial）。
- 构建命令：`dotnet publish -c Release -r osx-arm64 --self-contained`，产物在 `BatchCompress/publish/osx-arm64`。
- .app 结构：`BatchCompress.app/Contents/{Info.plist, MacOS/, Resources/}`，可执行文件名 `BatchCompress`。
- 项目当前**没有 git 仓库**，也没有 `.gitignore`、测试、CI。
- 项目规则要求：修改后版本号 +0.0.1（满十进一）、结束时清除旧进程、构建 .app 并复制到 `/Applications` 运行。
