## 阶段 P1：补齐核心能力

- [ ] **P1-1 真实进度**：压缩/解压追加 `-bsp1`（rar 用 `-idp`），解析百分比驱动进度条（注意退格符）；无法解析时回退为不确定进度
- [ ] **P1-2 解压目录策略**：默认解压到 `<归档名>/` 子目录（可切换“解到同一目录”），避免同名覆盖
- [ ] **P1-3 文件项参与解压/测试**：列表中的“文件”类型若本身是归档，直接对其解压/测试，不再只扫描文件夹
- [ ] **P1-4 格式能力校验**：gz/bz2/xz 选择“文件夹”时自动改走 `.tar.gz`/`.tar.bz2`/`.tar.xz`（或灰掉该选项并提示）；tar.gz 解压自动接力第二层（`7zz x -so | tar x`）
- [ ] **P1-5 跳过已压缩文件落地**：勾选后追加 `-xr!*.zip -xr!*.7z -xr!*.rar -xr!*.gz -xr!*.bz2 -xr!*.xz -xr!*.mp4 ...`
- [ ] **P1-6 分卷归档识别**：移植 `Google-compress` 项目的 `ArchiveVolumeResolver`（首卷判定、卷编号连续性检查、`part10` 排在 `part9` 之后、非首卷跳过）；扩展名匹配优先分卷正则（`part+rar$`、`7z+$`、`zip+$`）
- [ ] **P1-7 路径与前处理校验**：保存路径非空且自动创建、源去重、源不存在时标红、归档名冲突自动加序号
- [ ] **P1-8 退出码语义**：0 成功、1 警告（不判失败，日志提示）、≥2 失败
- [ ] **P1-9 加密增强**：7z 增加 `-mhe=on` 选项（加密文件名）；zip 使用 `-mem=AES256`；密码不写入日志明文
- [ ] **P1-10 结果汇总**：每项任务结束后在列表标记成功/失败，底部输出“成功 N / 失败 M / 跳过 K”
